# Game Tweaks
A [Town Of Us Mira](https://github.com/AU-Avengers/TOU-Mira) addon adding **Tweaks** which enchance the game.

The mod currently has **16** Tweaks for you to mess with, each one making the game a little different and unique.

You can see the tweaks currently active during a game using the cog icon next to your task bar.

## Tweaks
- **Anomaly:** Random tweaks are added at the start of the game.
- **Brutal Crew:** All role penalties for executing a crew teammate are disabled.
- **Chat Whispers:** Players can whisper to each other using a special command, hiding the contents of their messages from others.
- **Compliant Killers:** All Neutral Killers work together.
- **Divine Intervention:** Every round, a random room is selected as Protected. No one can die in this room.
- **Don't Fear the Reaper:** You are able to use one of your abilities shortly after death.
- **Election:** A Sovereign will be elected during the first meeting. The elected person permanently gains votes based on how many players voted him to be elected. A new one can be elected when the original one dies.
- **Graveyard:** Roles of dead players are revealed to everyone.
- **Haunted House:** Everyone will see dead players.
- **Impostoromicon:** Only one Impostor is allowed to kill. The rest can only use their normal abilities. The impostors can choose which teammate gains the power of murder.
- **Live Voting:** Votes on each player will be visible live.
- **Merry Go Round:** Roles of random players in the same team are swapped every round.
- **No Skip:** Players all not allowed to skip a meeting.
- **Perfect Crew:** All crewmates will die when a crew member is ejected or executed by another crew member.
- **Tactical Deployment:** When the round starts, players are able to choose their spawn location (like on Airship and Submerged).
- **VIP:** One crewmate will become the VIP. Every crew member learns who the VIP is and their role. When the VIP dies, all crewmates die. VIP disconnecting will reroll a new one if possible.

The **In-Game Wiki** contains a detailed explanation of all tweaks in the last section of the **Terminology** page.

## Installation
Find the [latest](https://github.com/xChipseq/GameTweaks/releases/latest) release, download the `.dll` file.

Locate your mod folder and put the downloaded file into the `BepInEx/plugins` folder.
